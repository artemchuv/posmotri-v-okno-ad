# Посмотри в окно

Проектная работа по оформлению готового приложения для поиска видео по городу и времени суток.

## Что сделано

- Сверстаны две основные области: видеоплеер с формой поиска и список карточек.
- Оформлены поле ввода, чекбоксы, кнопки и состояния карточек.
- Предусмотрены прокрутка списка, загрузка и отображение ошибки.
- Существующая логика поиска и воспроизведения видео сохранена.

## Как открыть

Откройте `index.html` в браузере. Для загрузки видео требуется подключение к интернету.

Основные стили находятся в `styles/style.css`.
